# Store properties recommendation

## Product identity

- Store title: **Duplicate File Cleaner Pro**
- Release candidate version: `1.0.0.0`
- Minimum OS: Windows 10, version 2004 (build 19041)
- Tested target OS: Windows 11, version 24H2 (build 26100)
- Architectures prepared: x64, x86, ARM64

## Category

Recommend **Utilities + tools** with the **File managers** subcategory, subject
to the categories currently offered by Partner Center. The app finds verified
exact duplicate local files, presents a manual review workflow, and can move
approved files to the Windows Recycle Bin.

## Account-owner input still required

- Support email address and/or support website
- Public privacy-policy URL after hosting `store/privacy-policy.html`
- Markets, availability, pricing, trials, and any commercial terms
- Final Partner Center identity and display-name association

Use Microsoft standard Store license terms unless the account owner obtains
appropriate legal advice and intentionally supplies alternative terms.
