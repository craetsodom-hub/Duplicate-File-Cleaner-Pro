# Store assets

`screenshots/` is reserved for unedited, PID/HWND-validated captures of the
release candidate. Do not place test corpora, developer desktop captures, or
marketing overlays here.

The current package `StoreLogo.png` is a 1x1 transparent placeholder. This
directory intentionally contains no invented replacement artwork. Before Store
submission, provide approved application artwork at every manifest-required
scale and copy the corresponding listing assets here.
