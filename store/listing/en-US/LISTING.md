# en-US Store listing draft

## Title

Duplicate File Cleaner Pro

## Short description

Find verified exact duplicate files, review them safely, and move approved copies to the Windows Recycle Bin.

## Full description

Duplicate File Cleaner Pro helps you find exact duplicate files in folders you
choose. It verifies file content before grouping matches, then gives you a clear
review view for deciding which copies to keep.

Review candidates manually before cleanup. When you choose to remove a verified
duplicate, the app uses the Windows Recycle Bin rather than permanent deletion.
Files are checked again before the move, and the app keeps at least one
independent verified copy in every duplicate group.

Your scan stays on your device. The app has no account, telemetry, analytics,
cloud processing, scan history, or cleanup history.

## Features

- Finds verified exact duplicate content, not filename-only matches
- Scans local folders you explicitly select
- Lets you search, sort, filter, expand, and manually review duplicate groups
- Keeps selection review factual; nothing is removed until you confirm cleanup
- Moves approved candidates to the Windows Recycle Bin
- Supports Light, Dark, and system appearance settings
- Uses a keyboard-accessible native Windows interface
