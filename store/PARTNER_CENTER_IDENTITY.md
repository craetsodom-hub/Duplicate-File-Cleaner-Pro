# Partner Center identity handoff

This repository has no `Package.StoreAssociation.xml` and no authoritative
Partner Center identity metadata. The current manifest is a development identity
only:

| Manifest field | Current value |
| --- | --- |
| `Identity/@Name` | `DuplicateFileCleanerPro` |
| `Identity/@Publisher` | `CN=DuplicateFileCleanerPro` |
| `Identity/@Version` | `1.0.0.0` |
| `Properties/DisplayName` | `ms-resource:AppDisplayName` → Duplicate File Cleaner Pro |
| `Properties/PublisherDisplayName` | Duplicate File Cleaner Pro |
| Application ID | `App` |

Before the first Partner Center upload, the account owner must reserve/associate
the product and supply the exact Partner Center-generated values for:

- package identity name;
- publisher distinguished name;
- publisher display name, if Partner Center supplies one;
- Store association XML/metadata, if generated by the association workflow;
- final product display-name reservation.

Apply those exact values only through the approved association workflow in
`src/DuplicateFileCleanerPro.App/Package.appxmanifest` (and any generated
association file). Do not substitute guessed company or publisher data. The
present development package family is not a claim about the eventual Store
family name.
