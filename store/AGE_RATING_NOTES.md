# IARC age-rating notes

Duplicate File Cleaner Pro is a local Windows file-management utility. The
following facts can be used when the account owner completes the current Partner
Center/IARC questionnaire:

- No user-generated public content, social interaction, chat, or accounts.
- No advertising, gambling, sexual content, violence, profanity, drugs,
  alcohol, tobacco, or mature narrative content.
- No location, microphone, camera, contacts, or account-data features.
- No online services, uploads, telemetry, analytics, or cloud processing.
- The app reads files from folders explicitly selected by the user and may move
  user-approved duplicate candidates only to the Windows Recycle Bin.

This document is preparation only. The account owner must answer the live IARC
questions in Partner Center and must not claim an IARC ID until one is issued.
