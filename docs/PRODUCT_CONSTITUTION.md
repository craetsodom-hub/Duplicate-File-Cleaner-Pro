# Product Constitution

## Purpose

Duplicate File Cleaner Pro will help users identify and safely review exact duplicate local files before optional Recycle Bin cleanup.

## Authority

This constitution governs product functionality. It outranks screenshots and visual references, which may guide appearance only.

## v1 scope

v1 is limited to exact local-file duplicates and the stages of scan setup, scanning, verified results, cleanup review, and settings.

## Permanent constraints

- A file is a duplicate only when its content is proven exactly equal; metadata alone is never proof.
- Cleanup in v1 uses the Windows Recycle Bin only; permanent deletion is excluded.
- v1 has no network/NAS or cloud scanning, accounts, telemetry, filename/content transmission, or persistent scan or cleanup history.
- v1 has no automatic cleanup or global smart selection; users retain explicit, reviewable control.
- Similar-photo, perceptual, archive-content, filename-only, alternate-checksum, scheduled/background, registry/system-cleaning, advertising, and AI features are out of scope.
- No administrator elevation, ACL/ownership manipulation, or security-boundary changes are permitted.

User-file safety takes priority over performance and convenience.
