# ADR-0008: Store and Development Package Separation

Status: Accepted.

Development package identity is explicit and separate from future Partner Center values. The Phase 0 development-only package was built with `runFullTrust`, registered from the current expanded output, launched by its current package identity, and unregistered after the probe. Store identity fields, final icon, Store locales, and production package signing remain external Phase 9/10 decisions.
