# Roadmap

1. Phase 0 - feasibility and safety evidence.
2. Phase 1 - solution foundation, documentation, settings, temp ownership, localization, tests, and development packaging.
3. Phase 2 - native shell and scan setup, followed by manual shell QA.
4. Phase 3 - bounded exact-duplicate scan engine and benchmarks.
5. Phase 4 - scan experience and results, followed by manual results QA.
6. Phase 5 - selection rules and retention invariant.
7. Phase 6 - recovery-safe removal, followed by manual destructive QA on generated corpus only.
8. Phase 7 - accessibility, localization, and polish.
9. Phase 8 - privacy, cleanup, and release UX.
10. Phase 9 - branding after user-approved icon.
11. Phase 10+ - Partner Center, compatibility, certification, and release gates requiring external information or manual QA.
